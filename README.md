#  RepoBot
*'cause I dunno why tf I was trying to have an LLM use skills to manage templated project config/docs for me, so now we're doing it properly*

macOS app for managing, updating, and syncing the identical project docs that *sometimes* get updated in one place, but never seem to be in sync anywhere. I want changes to find their way into 100 repos on their own, get themselves staged, committed, and pushed, if not merged via pr. So, this is my ongoing attempt at let'automating that in a reliable, deterministic, and user-friendly fashion.
